# Security policy

## Reporting a vulnerability

Please use GitHub's private security-advisory feature once the repository is online. Do not put
an exploitable issue, a credential, a console identifier or private system data in a public issue.

For ordinary crashes and compatibility problems, open a normal issue and include the game,
version, build revision and relevant excerpt from `ps4_log.txt`. Remove IP addresses, usernames,
tokens and other personal information before attaching a log.

## Supported version

Only the latest public source revision is supported. This is an unofficial homebrew project and
is provided without warranty.
